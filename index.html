1) أساسيات الشبكات

يعني إيه Network؟

  • مجموعة أجهزة مستقلة متوصلة ببعض عشان تتشارك الداتا والـ peripherals (الـ Sharing هو الهدف).
  • الشبكة بتتبني من 3 مكونات: Devices + Media + Services.

العناصر الأربعة للـ Communication

RulesProtocols — دلوقتي TCP/IP
Messagesبتتحول لـ Bits (0/1)
Mediumالوسيط الناقل
DevicesEnd / Intermediary
💡 Distance مش من عناصر الـ Communication (جت في الميد 2024).

الأجهزة (Devices)

  • End devices (Hosts): PC, Laptop, Printer, VoIP phone.
  • Intermediary: Hub/Switch (Network Access) — Router (Internetworking) — Firewall (Security).

الـ Media — الداتا بتتبعت إزاي؟

MediumEncoding
Copper (Metallic)Electrical impulses
Fiber opticPulses of light
WirelessElectromagnetic waves
💡 اختيار الميديا: Bandwidth + Cost + Distance. لون الكابل ملوش علاقة 😄

عوامل جودة الاتصال

  • Internal: حجم الرسالة، تعقيدها، أهميتها.
  • External: جودة الـ pathway، عدد مرات التحويل، عدد الرسايل التانية على الشبكة.

3) الـ OSI Model (ISO — 7 Layers)

7Application خدمات لبرامج اليوزر (HTTP, FTP, DNS…) — Data
6Presentation Format (ASCII/JPG) + Encryption + Compression
5Session Start / manage / end sessions — Dialog control — Checkpoints
4Transport TCP/UDP — PDU = Segment — Port numbers
3Network IP + Routing — PDU = Packet
2Data Link MAC address + Framing — PDU = Frame
1Physical Bits على الـ medium
💡 Encapsulation = إضافة Header/Trailer في كل layer. العكس De-encapsulation.
حفظ: Physical→Bits, DL→Frames, Network→Packets, Transport→Segments.

TCP/IP vs OSI

الـ TCP/IP هو المعيار الحالي (4 layers). الـ Application layer في TCP/IP بتعرّف protocols للتطبيقات وبتجمع Application + Presentation + Session.

6) Network Layer (IP)

  • أربع عمليات: Addressing – Encapsulation – Routing – Decapsulation.
  • IPv4: Connectionless (مفيش اتصال قبل الإرسال) + Best effort / Unreliable + Media independent.
  • IP address = 32 bit. الـ Header فيه: TTL, Protocol, Checksum, Source/Dest IP.
  • بروتوكولات مساعدة: ICMP, ARP.
  • الـ Link-state routing بيبعت LSAs بدل الـ routing table كلها.

7) Data Link Layer

  • الـ PDU = Frame. بتعمل: framing + error detection + media access control.
  • الـ MAC address = 48 bit (Physical) — بيتكلم جوه نفس الـ LAN.
  • ARP: بيحوّل IP ↔ MAC.
SublayerالدورStandard
LLCبيحدد أنهي Network protocol الـ frame تابع له — بيكلم Network layerIEEE 802.2
MACAddressing + بداية/نهاية الـ frame + media access — بيكلم PhysicalIEEE 802.3 (Ethernet) — CSMA/CD
💡 تقسيم الـ DL لـ sublayers = frame واحد يشتغل على media مختلفة. الـ Wireless = 802.11. الـ MAC مش بيكلم الـ Network layer مباشرة. و"طريقة تركيب الـ frame على الميديا" اسمها Media Access Control مش LLC (فخ في الميد!).

⚡ فخاخ الامتحان

  • Router = Internetworking، Firewall = Security، Hub = Network access.
  • Placing frames on medium = MAC (Data Link) مش Network layer.
  • P2P = كل الأجهزة متساوية.
  • Fiber = Light، Copper = Electrical.
  • UDP لـ streaming، TCP لـ reliable.
